Agents load skills through progressive disclosure in three stages:
Progressive Disclosure
1. Discovery: At startup agents load the entire skill into local memory, but 
sends only the name and description of each available skill to the LLM
2. Activation: When a task matches a skill description, the agent sends the 
full SKILL.md instructions and related ﬁles into the LLM context
3. Execution: The agent follows the instructions, optionally executing 
bundled code or loading referenced ﬁles as needed
