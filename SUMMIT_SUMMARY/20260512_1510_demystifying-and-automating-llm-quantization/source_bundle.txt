Quantization, Sparsiﬁcation, and Compression
6
▸
Quantization: Reduces model memory by representing weights and activations (i.e model layer 
inputs/outputs) using a lower bit representation (e.g int8). Allows models to use less storage. To quantize 
values to their new, low precision range:
▸
Sparsiﬁcation: Certain model weight values are zeroed out. This can be done in a particular pattern, such 
as 2 of 4 where 2 out of every 4 values within a model weight tensor are set to 0.
▸
Compression: Saving the model in a reduced size (with minimal impact to model accuracy)
